# 32-Bit RISC-V Processor Design & ASIC Implementation

An ongoing project focused on designing and verifying a 32-bit RISC-V single-cycle processor using Verilog HDL, with plans for ASIC synthesis, timing analysis, and physical implementation.

## Features
- 32-bit ALU supporting ADD, SUB, AND, and OR
- Zero flag generation for branch operations
- Register File, Program Counter, and Control Unit (Planned)
- RV32I instruction subset implementation (Planned)

## Technologies
- **Used:** Verilog HDL, Icarus Verilog, EDA Playground, EPWave
- **Planned:** Python, Yosys, OpenSTA, Tcl, OpenROAD

## Verification Results
- Initial ALU simulation: **5/5 tests passed**
- Automated ALU verification: **11/11 tests passed**
- Verified arithmetic, logical operations, zero flag functionality, and selected boundary conditions.
